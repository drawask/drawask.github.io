Extract table from DWG online

Civil and shop drawings often store the useful numbers as text grids, not Excel. CadChat clusters labeled text into tables so you can export CSV or paste them into ChatGPT.

Extract tables from your DWG

Examples CadChat looks for

  • Profile datasheets: GROUND ELEVATION, TOP PIPE, DEPTH TO EXC + STATION headers
  • Drawing index: PART 1, FROM ST 0+000 TO 1+000, DRAWING NO.
  • Other labeled numeric schedules on content layers

Tips for better table detection

  1. Keep label layers visible (for example C-LABELS)
  2. Hide pure drafting noise if needed
  3. Use region select around one datasheet when the sheet is crowded
